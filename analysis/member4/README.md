# Member 4: error analysis and uncertainty

**Use [`final/`](final/) for the team report and video.** It analyzes the integrated Member 2 features and Member 3 Round 8 tuned models on the official December 2025-May 2026 walk-forward validation predictions. The ready-to-use findings and voice-over are in [`final/report/VIDEO_FINDINGS.md`](final/report/VIDEO_FINDINGS.md). Three charts and grouped error tables are in `final/figures/` and `final/tables/`. Run `final/analyze_errors.py` from its directory to regenerate the analysis.

[`baseline_archive/`](baseline_archive/) preserves Member 4's earlier baseline analysis, including its supporting PDF and executable code. **Its metrics and voice-over are historical and must not be used as the final-model results.**

The repository's root `validation_predictions.csv`, `features.py`, `models.py`, and submission files remain the team's integrated model artifacts. The final analysis also carries a copy of its input predictions and validation metadata so it can be reproduced on its own.
